# Changelog

## 0.1.0 (2026-10-13)

First public version.

- Cinematic 3D server room: racks sized from your data, LEDs, drive bays, uplink cables with traffic packets
- Camera autopilot with six shot types and alarm cut-ins; free camera; rack focus with details; TV mode
- Proxmox VE connector: read-only token, counter-based rates, SMART health, shared storage rack, `onboot`-aware alarms
- Zero-dependency Node server with shared polling cache and optional basic auth
- Demo mode with a simulated homelab (live at csiber.github.io/rackscape)
- Embedding via `postMessage` (`?source=embed`)
- Docker image for amd64 and arm64
